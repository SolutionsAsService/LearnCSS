CSS Basics

CSS is a list of rules. Each rule picks elements and says how they look.

Three ways to add CSS

You can write CSS in three places. Use the last one for real projects.

<p style="color: coral">Inline: one element only</p>

<style>
  p { color: coral; }   /* Internal: one page */
</style>

<link rel="stylesheet" href="styles.css">   <!-- External: every page -->

The shape of a rule

selector {
  property: value;
}

The selector says which elements. Each declaration is a property, a colon, a value and a semicolon.

Units you will use

  • rem scales with the reader's font size. Use it for type and spacing.
  • % and vw follow the container or screen.
  • px is fixed. Fine for borders, risky for text.
Common mistake. A missing semicolon silently breaks the next line. If a style "does nothing", look one line up.
