Flexbox

Line items up in a row or a column and let the browser share the space.

Push the items around

Row, space-between, centred, 4 items, gap 8px.

Turn on JavaScript for the controls. The row to the right shows the default result.

1234
.container {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  flex-wrap: nowrap;
  gap: 8px;
}

Two axes, two properties

A flex container has a main axis (the direction) and a cross axis across it. justify-content spreads items along the main axis, align-items along the cross axis. Change flex-direction above and watch the two swap jobs.

Items can ask for room

.item { flex: 1; }          /* share spare space equally */
.item.wide { flex: 2; }     /* take twice the share */
.item.fixed { flex: none; width: 120px; }
Common mistake. Putting display: flex on the items instead of their parent. Flex works on the children of the element that has it.
