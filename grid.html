CSS Grid

Lay out rows and columns together, then let the grid adapt to the screen.

Draw a grid

3 columns, gap 8px, 6 items.

Turn on JavaScript for the controls. The grid shows three equal columns.

123456
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 8px;
}

Rows and columns together

Flexbox lays things out in one direction. Grid does both at once, so use it for whole-page layouts and card walls. 1fr means "one share of the free space".

A layout that adapts without a media query

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(6rem, 1fr));
  gap: 1rem;
}

Choose minmax in the lab above and narrow your window: the columns drop to fit.

Common mistake. Reaching for grid to centre one thing. display: grid; place-items: center; does it in two lines.
