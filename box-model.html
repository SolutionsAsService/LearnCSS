The Box Model

Every element is four nested boxes. Know them and spacing stops being guesswork.

Build a box

Painted width = 140 + 2×16 + 2×8 = 188px. With margin: 236px (default content-box sizing).

margin
border
padding
140 px
.box {
  width: 140px;
  padding: 16px;
  border: 8px solid;
  margin: 24px;
}

Four layers

  • Content: the text or image.
  • Padding: space inside, between content and border. It shows the background.
  • Border: the edge.
  • Margin: space outside, pushing other elements away. It is always transparent.

The one line that fixes the arithmetic

By default width is the content only, so padding and border make the box wider than you wrote. Switch to a sum that includes them:

*, *::before, *::after {
  box-sizing: border-box;
}

.card { width: 300px; padding: 20px; border: 10px solid; }
/* painted width is now 300px, not 360px */
Common mistake. Using margin to pad the inside of a box. Margin never takes the background colour; padding does.
