# Learn CSS

A free, hands-on guide: six short lessons (basics, selectors, box model, flexbox, grid, animations). Each has a live playground that prints the exact CSS it just made. No build step, no dependencies: open `index.html`.

## Files

| Path | What |
|---|---|
| `index.html` | The first screen: six lessons drawn with the CSS they teach, a box-model lab, the path |
| `basics.html` ... `animations.html` | One lesson each, in order |
| `styles.css` | The one stylesheet, tokens first, light and dark |
| `app.js` | The playgrounds (about 100 lines, no libraries) |
| `DESIGN-LOG.md` | How this redesign was made and judged |

## Develop

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

The lesson pages share a header and footer by copy. See `CONTRIBUTING.md` for how to send a change.
